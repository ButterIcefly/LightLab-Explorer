## ✨ 项目介绍

🌟 小光实验室是一款互动式科学实验作品。

它尝试解决一个问题：

> ❓ 为什么影子会出现？

<div align="center">

相比直接告诉答案，项目采用探索方式：

💡 提出问题<br>
↓<br>
👀 观察现象<br>
↓<br>
🎛 调整条件<br>
↓<br>
💭 提出猜想<br>
↓<br>
🧪 实验验证<br>
↓<br>
🌟 建立理解

让学习者通过操作逐渐形成科学模型。

</div>
